# Casos de uso — Hexavante Desktop

Documento de referência dos fluxos **implementados**.

---

## UC-01 — Primeiro acesso

1. Abre o app instalado → tela de login.
2. Entra com e-mail/senha ou OAuth (navegador do sistema retorna ao app).
3. Cai no catálogo com a sessão persistida.

## UC-02 — Estudar offline-friendly

1. Abre um curso → progresso sincroniza quando há rede.
2. Sem rede: aviso visível + fila de ações.

## UC-03 — Fazer simulado

1. Lista com filtros → detalhe → prova com cronômetro → resultado e histórico.

## UC-04 — Atualizar o app

1. Baixa o instalador da versão nova → instala por cima → sessão mantida.
